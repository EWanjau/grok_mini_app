# NSSF on total gross (not basic only)

Kenyan employers sometimes pension NSSF on basic pay only; this product computes NSSF as 6% of **total gross**, capped at KES 6,480 per month, matching the same gross base used for SHIF and Housing Levy. The results screen includes a short note that employer practice may differ so users do not treat the figure as payroll-system gospel.
